# Controller Python Compatibility Window

## Exit policy

Phase 4 uses the migration design's **two tagged releases** option. Both releases retain the PowerShell forwarding shims and the historical PowerShell oracle. Phase 5 may begin only after both tags are published, their controller matrices pass on Windows, Ubuntu, and macOS with Python 3.10 and the newest supported minor, and no unresolved P0/P1 parity defect is recorded.

## Shim-supported releases

| Release | Purpose | Runtime status |
| --- | --- | --- |
| [`controller-python-v1.0.0-shim`](https://github.com/Ven0304/vibe-design-arena/releases/tag/controller-python-v1.0.0-shim) | Opens the compatibility window from commit `32bc93d`; establishes Python as canonical after the Phase 3 6/6 matrix. | Python canonical; both `.ps1` forwarders supported. |
| `controller-python-v1.0.1-shim` | Closes the compatibility window after the expanded retirement-gate suite passes. The GitHub release records the final CI run and exact commit. | Last release supporting both `.ps1` forwarders. |

The direct replacements throughout the window are:

```console
python scripts/arena.py <command> --state <absolute-path> ...
python scripts/arena_integrity.py <action> ...
```

## Retirement evidence

| Required evidence | Automated proof |
| --- | --- |
| Windows differential parity | `controller-differential.ps1` against the retained Phase 2 oracle before retirement. |
| Linux/macOS lifecycle | Six-job `Controller Contract` CI matrix. |
| Lock contention | `test_lock_contention_fails_without_revision_change`. |
| Controller interruption | `test_controller_interruption_keeps_old_state_and_releases_lock`. |
| Atomic replace failure | `test_atomic_replace_failure_preserves_old_state_and_cleans_temp`. |
| Process-tree cleanup and unrelated-process safety | `test_process_tree_stop_does_not_terminate_unrelated_process` plus PID-reuse simulation. |
| Old valid state resume | A normalized state generated by the real PowerShell controller, exercised by `test_python_resumes_normalized_powershell_v1_state_fixture`. |
| Node PASS/FAIL/BLOCKED and malformed imports | Full lifecycle plus entrypoint negative tests and the retained Node unit contract. |
| Merge conflict and user-authorized resume | Full lifecycle conflict path; `MERGE_HEAD` remains until explicit resolution. |
| Cleanup refusal | Full lifecycle injects an ambiguous untracked file and proves that no candidate worktree is removed. |
| Partial publish and branch retention | Full lifecycle publishes only `style-b`, removes all three worktrees, and verifies all three branches at recorded commits. |
| Validator and documentation links | Skill validator, syntax/schema checks, dynamic-execution scan, and local-link audit. |
