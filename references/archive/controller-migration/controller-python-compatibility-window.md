# Controller Python Compatibility Window

## Status

Phase 4 is complete. The selected **two tagged releases** both retained the PowerShell forwarding shims, passed the `Controller Contract` matrix on Windows, Ubuntu, and macOS with Python 3.10 and the newest supported minor, and had no unresolved P0/P1 parity defect. Phase 5 retired the shims after the second gate.
